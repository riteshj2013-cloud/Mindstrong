# Letters & Words

## Meta
- Grade: 1
- Subject: English
- Theme tags: letters-words
- Source basis: NCERT Class 1 themes (original items only)
- Language: Grade 1 (very short sentences)

## Learning objectives
- Age-appropriate olympiad-lite practice for Grade 1.
- Set A and Set B have 16 MCQs each (32 total).

## Set A — 16 MCQs

### Q1
- stem: Which letter comes after "B"?
- A: A
- B: C
- C: D
- D: E
- answer: B
- explanation: A, B, C — C comes after B.

### Q2
- stem: Which word starts with M?
- A: sun
- B: moon
- C: cat
- D: dog
- answer: B
- explanation: Moon starts with M.

### Q3
- stem: Find the word: "c" + "at" =
- A: bat
- B: cat
- C: hat
- D: mat
- answer: B
- explanation: c + at makes cat.

### Q4
- stem: Which is a letter?
- A: 3
- B: A
- C: !
- D: 10
- answer: B
- explanation: A is a letter of the alphabet.

### Q5
- stem: How many letters are in the word SUN?
- A: 2
- B: 3
- C: 4
- D: 1
- answer: B
- explanation: S-U-N has 3 letters.

### Q6
- stem: Which word ends with "g"?
- A: bag
- B: bat
- C: bus
- D: bee
- answer: A
- explanation: Bag ends with g.

### Q7
- stem: Capital letter for a is…
- A: A
- B: B
- C: a
- D: E
- answer: A
- explanation: The capital of a is A.

### Q8
- stem: Which word means a pet that meows?
- A: dog
- B: cat
- C: cow
- D: hen
- answer: B
- explanation: A cat meows.

### Q9
- stem: Rhymes with "hat"?
- A: hot
- B: sit
- C: cat
- D: cup
- answer: C
- explanation: Cat rhymes with hat.

### Q10
- stem: First letter of INDIA is…
- A: N
- B: I
- C: D
- D: A
- answer: B
- explanation: INDIA starts with I.

### Q11
- stem: Which is a word?
- A: xyzq
- B: book
- C: 1234
- D: ##
- answer: B
- explanation: Book is a real word.

### Q12
- stem: Ball starts with which sound?
- A: b
- B: c
- C: d
- D: s
- answer: A
- explanation: Ball starts with /b/.

### Q13
- stem: How many vowels in AEIOU list?
- A: 3
- B: 4
- C: 5
- D: 6
- answer: C
- explanation: A E I O U — five vowels.

### Q14
- stem: Small letter for "T" is…
- A: t
- B: T
- C: s
- D: l
- answer: A
- explanation: Small form of T is t.

### Q15
- stem: Which word names a colour?
- A: run
- B: red
- C: cup
- D: sit
- answer: B
- explanation: Red is a colour.

### Q16
- stem: Join: bl + ue =
- A: blue
- B: blow
- C: glue
- D: clue
- answer: A
- explanation: bl + ue = blue.
