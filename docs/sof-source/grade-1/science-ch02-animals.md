# Animals

## Meta
- Grade: 1
- Subject: Science
- Theme tags: animals
- Source basis: NCERT Class 1 themes (original items only)
- Language: Grade 1 (very short sentences)

## Learning objectives
- Age-appropriate olympiad-lite practice for Grade 1.
- Set A and Set B have 16 MCQs each (32 total).

## Quiz Set A — 16 MCQs

**Q1.**

**Stem:** Which animal says meow?

**Options:**
- A) cat
- B) dog
- C) cow
- D) frog

**Answer:** A

**Explanation:** A cat says meow.

**Q2.**

- D) clouds
