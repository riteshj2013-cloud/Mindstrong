# Shapes

## Meta
- Grade: 1
- Subject: Maths
- Theme tags: shapes
- Source basis: NCERT Class 1 themes (original items only)
- Language: Grade 1 (very short sentences)

## Learning objectives
- Age-appropriate olympiad-lite practice for Grade 1.
- Set A and Set B have 16 MCQs each (32 total).

## Practice Set A — 16 MCQs

### Q1
- **stem**: A round ball looks most like a…
- A) square
- B) circle
- C) triangle
- D) rectangle
- **answer**: B
- **explanation**: A ball is round like a circle.

### Q2
- **stem**: How many sides does a triangle have?
- A) 2
- B) 3
- C) 4
- D) 5
- **answer**: B
- **explanation**: A triangle has 3 sides.

### Q3
- **stem**: A square has how many equal sides?
- A) 2
- B) 3
- C) 4
- D) 5
- **answer**: C
- **explanation**: A square has 4 equal sides.

### Q4
- **stem**: Which shape has no corners?
- A) square
- B) triangle
- C) circle
- D) rectangle
- **answer**: C
- **explanation**: A circle is smooth — no corners.

### Q5
- **stem**: A book cover looks most like a…
- A) circle
- B) triangle
- C) rectangle
- D) ball
- **answer**: C
- **explanation**: A book is longer one way — a rectangle.

### Q6
- **stem**: How many corners does a square have?
- A) 2
- B) 3
- C) 4
- D) 0
- **answer**: C
- **explanation**: A square has 4 corners.

### Q7
- **stem**: Which shape looks like a slice of pizza?
- A) circle
- B) triangle
- C) square
- D) oval
- **answer**: B
- **explanation**: A pizza slice is triangle-shaped.

### Q8
- **stem**: A door is often shaped like a…
- A) circle
- B) triangle
- C) rectangle
- D) star
- **answer**: C
- **explanation**: Most doors are rectangles.

### Q9
- **stem**: Which has 3 corners?
- A) circle
- B) square
- C) triangle
- D) rectangle
- **answer**: C
- **explanation**: A triangle has 3 corners.

### Q10
- **stem**: A clock face is most like a…
- A) square
- B) circle
- C) triangle
- D) box
- **answer**: B
- **explanation**: A clock face is round — a circle.

### Q11
- **stem**: How many sides does a rectangle have?
- A) 2
- B) 3
- C) 4
- D) 6
- **answer**: C
- **explanation**: A rectangle has 4 sides.

### Q12
- **stem**: Which shape can roll easily?
- A) square
- B) triangle
- C) circle
- D) rectangle
- **answer**: C
- **explanation**: A circle rolls.

### Q13
- **stem**: A sandwich cut corner to corner makes…
- A) circles
- B) triangles
- C) squares only
- D) ovals
- **answer**: B
- **explanation**: Corner-to-corner cuts make triangles.

### Q14
- **stem**: All sides equal and 4 corners — what shape?
- A) triangle
- B) circle
- C) square
- D) oval
- **answer**: C
- **explanation**: Equal sides + 4 corners = square.

### Q15
- **stem**: Which is NOT a shape name?
- A) circle
- B) apple
- C) square
- D) triangle
- **answer**: B
- **explanation**: Apple is a fruit, not a shape name.

### Q16
- **stem**: A window pane is often a…
- A) circle
- B) triangle
- C) rectangle
- D) star
- **answer**: C
- **explanation**: Many window panes are rectangles.


## Practice Set B — 16 MCQs

### Q1
- **stem**: How many sides does a circle have?

- B) 1

- D) 4

- B) triangle
- C) square only
- D) line

- **explanation**: Many warning boards are triangles.

### Q3

- D) oval

### Q4
