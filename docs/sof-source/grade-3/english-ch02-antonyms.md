## Learning objectives
- I can say that antonyms are words with opposite meanings.
- I can pick an antonym for everyday Grade 3 words.
- I can try a word in a sentence to check if the meaning flips.
- I can spot when an option is a synonym (twin), not an antonym.

## Interactive lesson outline
- L1 (hook): Hello, word opposites! Some words mean the opposite thing.
- L2 (reveal): Tap hot → cold; big → small; happy → sad; up → down.
- L3 (demo): Swap hot for cold in a chai sentence — meaning flips.
- L4 (try): Antonym of brave? → scared.
- L5 (check): Which pair are antonyms? hot — cold (not big — large).
- L6 (wrap): Antonym = opposite. Sets ready — 24 MCQs each.
