# Grade 3 English — Chapter 1: Synonyms (Word Twins)

## Meta

## Learning objectives
- I can say that synonyms are words with nearly the same meaning.
- I can pick a synonym for everyday Grade 3 words.
- I can try a word in a sentence to check if it is a twin.
- I can spot when an option is an opposite, not a synonym.

## Interactive lesson outline
- L1 (hook): Hello, word twins! Some words mean nearly the same thing.
- L2 (reveal): Tap happy → glad; big → large; fast → quick; begin → start.
- L3 (demo): Swap happy for glad in a tiffin sentence — meaning stays.
- L4 (try): Synonym of brave? → courageous.
- L5 (check): Which pair are synonyms? big — large (not hot — cold).
- L6 (wrap): Synonym ≈ similar. Sets ready — 24 MCQs each.
