## Interactive Lesson Outline

### step_1: Joining groups
- **tts**:
  - Adding means joining groups. Two baskets of mangoes become one bigger pile.
  - Line up ones under ones, tens under tens, hundreds under hundreds.
- **on_screen**: Two baskets (34 and 25 mangoes) tip into one; place-value columns light up.
- **check**: What is 34 + 25? — Answer: 59

### step_2: Carry when ones overflow
- **tts**:
  - When ones add to ten or more, we write the ones digit and carry one ten.
  - Seven plus eight is fifteen: write five, carry one ten.
- **on_screen**: Ones tiles overflow into a ten-bundle that hops to the tens column.
- **check**: What is 47 + 38? — Answer: 85

### step_3: Borrow when ones are too small
- **tts**:
  - If you cannot subtract ones, borrow one ten. That ten becomes ten ones.
  - In fifty-two minus twenty-eight, borrow so ones become twelve.
- **on_screen**: A ten stick unties into ten ones; child completes 52 − 28.
- **check**: What is 52 − 28? — Answer: 24

### step_4: Zeros need careful borrowing
- **tts**:
  - Numbers like four hundred need step-by-step borrowing across the zeros.
  - Always check by adding your answer back.
- **on_screen**: Place-value chart for 400 − 176 with borrow arrows; check 224 + 176.
- **check**: What is 400 − 176? — Answer: 224

### step_5: Check strategies
- **tts**:
  - Addition and subtraction are partners. To check a subtraction, add.
  - Estimating first helps you spot a wild answer.
- **on_screen**: Balance card: 91 − 47 = 44 checks with 44 + 47 = 91; estimate 198 + 203 ≈ 400.
- **check**: How do you check 91 − 47 = 44? — Answer: Add 44 + 47

### step_6: Money stories with rupees
- **tts**:
  - Shop stories use rupees. Together means add. Change means subtract.
  - Remember the rupee sign — never dollars!
- **on_screen**: Kirana shop: pencil box ₹28, pay with ₹50, change appears.
- **check**: ₹50 − ₹28 = ? — Answer: ₹22

### step_7: Missing numbers and fact families
- **tts**:
  - If three hundred forty-five plus something makes five hundred, subtract to find the something.
  - Eight plus seven is fifteen, so fifteen minus eight is seven.
- **on_screen**: Blank number cards and a fact-family triangle for 8, 7, 15.
- **check**: 345 + ___ = 500. What fills the blank? — Answer: 155

### step_8: Two-step stories
- **tts**:
  - Some stories add first, then take away. Read carefully and do one step at a time.
  - You are ready for Set A and Set B!
- **on_screen**: Stamp story: start 148, get 76, give 50; child taps each step.
- **check**: 148 + 76 − 50 = ? — Answer: 174

## Practice Set A

### Q01
- **stem**: What is 234 + 152?
- **options**:
  - A) 386
  - B) 376
  - C) 396
  - D) 284
- **answer**: A
- **explanation**: Add ones: 4 + 2 = 6. Add tens: 3 + 5 = 8. Add hundreds: 2 + 1 = 3. So 234 + 152 = 386.
- **skill**: add_no_carry
- **difficulty**: easy

### Q02
- **stem**: What is 47 + 38?
- **options**:
  - A) 75
  - B) 85
  - C) 95
  - D) 70
- **answer**: B
- **explanation**: Ones: 7 + 8 = 15 → write 5, carry 1 ten. Tens: 4 + 3 + 1 = 8. So 47 + 38 = 85.
- **skill**: add_carry
- **difficulty**: easy
