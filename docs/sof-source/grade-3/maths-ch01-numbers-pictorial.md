## Engineering notes
- **Embedding**: Each MCQ has a fenced ```` ```svg ```` block right after the stem under `**Diagram (SVG):**`. Take the block contents as-is and insert them as inline SVG markup in the question card, between the stem and the options. Do not load them as `<img src>`, or the CSS classes stop working. Use the `**alt**` line as the accessible name; the root `<svg>` also has `role="img"` and an `aria-label`.
- **Self-contained**: Every SVG has a `viewBox` and `xmlns`, uses no external fonts, images, links or `<style>`, and sets fills and strokes as attributes, so it renders the same with no CSS at all. All 18 SVGs pass an XML parser check.
- **Countable pictures**: The stick bundles (fig_001), dot pairs (fig_013) and base-ten blocks (fig_017) are meant to be counted. Keep the aspect ratio (`height: auto`) and do not scale below about 300px wide, so each stick, dot and rod stays separate. Tap-to-zoom is recommended for fig_017 (12 rods).
- **Sizing**: Set `width: 100%; height: auto;` with the `max-width` from `css_notes` (300–480px). Digit tiles are small figures, so 300px is enough.
- **Theming and animation hooks**: There are class names on the elements: `.part` (all shapes), `.label` / `.value` / `.digit` (text), `.big-bundle` / `.ten-bundle` / `.loose` (sticks, which can be tied in a regrouping animation), `.hundred-flat` / `.ten-rod` / `.one-cube`, `.dot`, `.missing` (the ? card or carriage), `.point`, `.arrow`, `.highlight` (star), `.option-label` (A–D, Jar A–D, Group 1–4).
- **Labels in stems**: Stems name figure labels (Balloon A–D, Chart A–D, Jar A–D, Group 1–4, the star house, point P/Q, the ? card or carriage), and options use the same names.
- **Read-aloud**: The stems are short enough for TTS. Read `**alt**` after the stem for children who use audio.
- **Mixing**: Swap or add items using `replaces_hint`. 9 pictorial items in a 24-item set is about 37.5% visual.
- **Originality**: All figures, numbers and stems are new and were made for Mindstrong. No SOF or past-paper images, scans or traced layouts are used, only the general style (houses, bundles, tiles, number lines, jars, balloons).
