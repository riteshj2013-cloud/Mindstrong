## Engineering notes
- **Embedding**: Each MCQ has a fenced ```` ```svg ```` block right after the stem under `**Diagram (SVG):**`. Take the block contents as-is and insert them as inline SVG markup in the question card, between the stem and the options. Do not load them as `<img src>`, or the CSS classes stop working. Use the `**alt**` line as the accessible name; the root `<svg>` also has `role="img"` and an `aria-label`.
- **Self-contained**: Every SVG has a `viewBox` and `xmlns`, uses no external fonts, images, links or `<style>`, and sets fills and strokes as attributes, so it renders the same with no CSS at all. All 18 SVGs pass an XML parser check. The `₹`, `×` and `÷` characters are plain UTF-8 text, so serve the file as UTF-8.
- **Sizing**: Set `width: 100%; height: auto;` with the `max-width` from `css_notes` (300–480px). Do not scale below about 300px wide on phones, or the small labels get hard to read.
- **Theming and animation hooks**: There are class names on the elements: `.part` (all shapes), `.label` / `.value` (text), `.arrow` and `.jump` (number-line hops, which can be drawn one by one), `.counter` / `.laddoo` / `.mango` (objects that can be dealt into `.plate` / `.bag` / `.group`), `.leftover` (remainder zone), `.missing` (the ? corner or card), `.labelled` (grid cells P/Q/A–D) and `.option-label` (the A–D or 1–2 letters inside figures).
- **Labels in stems**: Stems name figure labels (Picture A–D, corners A/B/C, cells P/Q and A–D, Card A–D, Figure 1/2, Plate/Bag/Box/Bus numbers, point P), and options use the same names.
- **Mixing**: Swap or add items using `replaces_hint`. 9 pictorial items in a 24-item set is about 37.5% visual.
- **Originality**: All figures, numbers, names and stems are new and were made for Mindstrong. No SOF or past-paper images, scans or traced layouts are used, only the general style (arrays, equal groups, number-line jumps, fact triangles, box method, tables). Prices are made up for practice.
