## Interactive Lesson Outline

### step_1: Spot the Repeat
- **tts**:
  - Many patterns repeat a block again and again. Find the block, and count how long it is.
  - To find a far-away term, use the block length: the 9th term of a block of 2 is the same as the 1st.
- **on_screen**: A bead string slides in. The child taps where the beads start repeating, and the repeating block glows.
- **check**: Circle, square, circle, square, … What is the 9th shape? — Answer: Circle

### step_2: Number Series
- **tts**:
  - Write the gap between neighbouring numbers. The gaps may stay the same, grow, or double.
  - If the numbers jump up and down, try two lists that take turns.
- **on_screen**: Numbers sit on stepping stones; the gaps appear on little bridges between them, and odd and even stones light up in two colours.
- **check**: What comes next? 4, 9, 14, 19, ? — Answer: 24

### step_3: Letter Series
- **tts**:
  - Change letters into alphabet positions: A = 1, B = 2, and so on. Then find the number pattern.
  - Some letter series go backwards from Z, or mix two lists.
- **on_screen**: An alphabet strip lies under the letters, and each jump is drawn as an arc with its size written on it.
- **check**: Which letter comes next? C, F, I, ? — Answer: L

### step_4: Figure Patterns
- **tts**:
  - In a figure pattern, check one thing at a time: shape, number of sides, dots, shading, size and the way it points.
  - A figure can turn clockwise or anticlockwise by a quarter turn, a half turn or an eighth of a turn.
- **on_screen**: An arrow turns step by step while a checklist (shape, size, shading, turn, count) ticks off what changed.
- **check**: An arrow points up and turns a quarter turn clockwise each step. Where does it point after 2 steps? — Answer: Down

### step_5: Analogies
- **tts**:
  - 'A is to B as C is to D' means the change from A to B is the same as the change from C to D.
  - Find the rule from the first pair, test it, and then use exactly that rule on C.
- **on_screen**: Two pairs of cards sit side by side. The rule found on the first pair is copied onto the second pair as a glowing arrow.
- **check**: Using the rule 'multiply by 3': 4 is to 12 as 5 is to ? — Answer: 15

### step_6: Groups and Odd One Out
- **tts**:
  - To classify, find a rule that every member of a group shares, such as a times table or the number of sides.
  - For the odd one out, find a rule that three things share and the fourth does not. Check that no other rule picks a different answer.
- **on_screen**: Number cards drop into club baskets. A card that does not fit any basket is set aside as the odd one out.
- **check**: Which is the odd one out: 12, 24, 48, 27? — Answer: 27 (the only odd number)

### Q02
- **id**: g4-maths-ch09-a-02
- **stem**: Arjun writes this series on the class board: 3, 10, 5, 12, 7, 14, ?. Which number should replace the question mark?
- **options**:
  - A) 16
  - B) 21
  - C) 11
  - D) 9
- **answer**: D
- **explanation**: Two lists take turns. Places 1, 3 and 5 go 3, 5, 7 (add 2) and places 2, 4 and 6 go 10, 12, 14 (add 2). The missing number is in place 7, so it continues the first list: 7 + 2 = 9. 16 is tempting because it continues 10, 12, 14, but that list's next turn is place 8, not place 7.
- **hint**: Split the series into two lists that take turns. Which list does the missing place belong to?
- **skill**: interleaved_series
- **difficulty**: easy
- **type**: logical
- **pictorial**: no
- **olympiad_section**: logical

- Pictorial items: Set A Q01, Q04, Q06, Q08, Q10, Q12, Q14, Q16, Q19, Q20, Q22, Q23; Set B Q01, Q04, Q06, Q08, Q10, Q12, Q14, Q16, Q19, Q20, Q22, Q23.
- Figure kinds: shape trains and bead strings, turning arrows, shaded quarter-circles, moving shaded squares and dots on 3 × 3 grids, a dot hopping round a pentagon, tile staircases, matchstick triangles, unit-square figures, nested shapes, 2 × 2 and 3 × 3 matrices, figure analogies laid out as first : second :: third : ?, a number pyramid and a magic square.
- Exactness: every figure is drawn from the generator's data. Regular polygons are drawn from exact vertex lists (first vertex straight up, turned clockwise; a square's standard pose stands flat), so the verify script re-derives each shape's number of sides, size, turn and shading from the coordinates, counts the dots in each frame, reads arrow directions from the arrow tip, reads which quarter of a circle is shaded from the sector path, and reads shaded grid squares, unit squares and matchsticks from their rectangles and lines. It then re-applies each item's rule to the drawn figures to recompute the key.
- Uniqueness: odd-one-out items were checked against a library of simple number properties (even, multiples of 3 to 12, square, cube, prime, palindrome, digit sum and product, digit order, first/last digit, all-even or all-odd digits and others) and of figure properties (sides, dots, shading, size, squares, perimeter, width, height). Every property that singles out one option singles out the key. Series items were checked against families of simple rules (constant gap, constant ratio, gaps changing by a constant, gaps multiplying, multiply-then-add, add the two before, alternating additions or multiplications, two interleaved lists, growing multiplier); every family that fits the shown terms gives the key and no distractor. Number analogies were checked against about 1,000 relations (ax + b, squares and cubes ± k, x(x + 1), digit sum, digit reverse, division); no relation that fits the example(s) leads to a distractor. Figure analogies were checked against every combination of side, dot, shading, turn and size changes. Magnitude-only rules (largest, smallest) are not used as hidden rules.
- Scope guard: coding-decoding, ranking, alphabet-position puzzles, directions and mirror images belong to Chapters 10 and 11, so no item here uses mirror images or direction-sense stories.
- Every SVG is self-contained (no external fonts, CSS, scripts or images), carries `role="img"` + `aria-label`, and each item also has an `alt` line that names every printed number. Label text is 12–34 px in the viewBox; scale with `max-width: 100%; height: auto;`.
- olympiad_section values use the house tokens: `logical` = Logical Reasoning, `achievers` = Achievers. This chapter maps to Logical Reasoning, so the easy and medium items are `logical` and the 5 hard items in each set are `achievers`.
- All keys were computed and asserted by `/workspace/scratch/gen_g4ch9.py` (figures in `/workspace/scratch/g4ch9_figs.py`, uniqueness library in `/workspace/scratch/g4ch9_logic.py`); `/workspace/scratch/verify_g4ch9.py` re-checks the saved file, re-derives each pictorial key from the SVG geometry, re-runs the uniqueness checks and runs the review rules R1–R6.
