## Interactive Lesson Outline

### step_1
- Nested sets N ⊂ W ⊂ Z ⊂ Q ⊂ R; irrationals fill gaps in Q.

### step_2
- Terminating/repeating decimals ↔ rationals; non-repeating ↔ irrationals.

### step_3
- Simplify radicals; rationalise denominators with conjugates.

### step_4
- Exponent laws for positive bases and integer/rational exponents.

## Practice Set A

### Q01
- **stem**: Which of the following is an irrational number?
- **options**:
  - A) √2
  - B) √9
  - C) 0.25
  - D) 7/3
- **answer**: A
- **explanation**: √2 cannot be written as p/q in lowest terms; √9 = 3 and 0.25 = 1/4 are rational.
- **skill**: irrational
- **difficulty**: easy

### Q02
- **stem**: Every rational number can also be called a…
- **options**:
  - A) natural number
  - B) real number
  - C) integer
  - D) whole number only
- **answer**: B
- **explanation**: Rationals sit inside the reals. Not every rational is a natural number or integer.
- **skill**: sets
- **difficulty**: easy

### Q03
- **stem**: The decimal expansion of 1/8 is…
- **options**:
  - A) 0.121212… (non-terminating repeating)
  - B) 0.1121121112… (non-repeating)
  - C) √2
  - D) 0.125 (terminating)
- **answer**: D
- **explanation**: 1 ÷ 8 = 0.125 exactly, so the expansion terminates.
- **skill**: decimals
- **difficulty**: easy

### Q04

- **options**:

- **explanation**: Non-terminating non-repeating decimals define irrational numbers.
- **skill**: decimals
- **difficulty**: easy

### Q10

### Q11

### Q12

### Q13
- **stem**: On the number line, √2 lies between…

### Q14
- **stem**: Which law is correct for positive real a and integers m, n?
- **options**:
  - A) a^m * a^n = a^(m*n)
  - B) a^m * a^n = a^(m+n)
  - C) a^m * a^n = a^(m-n)
  - D) (a^m)^n = a^(m+n)
- **answer**: B
- **explanation**: When multiplying same bases, add exponents: a^m * a^n = a^(m+n).
- **skill**: exponents
- **difficulty**: easy

### Q15

### Q21
- **stem**: Which expression equals (3²)³?
- **options**:
  - A) both 3⁶ and 9³
  - B) 3⁵
  - C) 3⁶
  - D) 9³
- **answer**: A
- **explanation**: (3²)³ = 3⁶ because the powers multiply (2 × 3 = 6), and 9³ = (3²)³ = 3⁶ too, so both 3⁶ and 9³ are equal to it. 3⁵ may look right if you add the powers (2 + 3) instead of multiplying them.
- **skill**: exponents
- **difficulty**: medium

### Q23
- **stem**: Simplify: √50 − √18 + √8
- **options**:
  - A) 3√2
  - B) 2√2
  - C) 4√2
  - D) 5√2
- **answer**: C
- **explanation**: √50=5√2, √18=3√2, √8=2√2 → 5√2 − 3√2 + 2√2 = 4√2.
- **skill**: surds
- **difficulty**: hard

### Q24
- **stem**: If a = 2 + √3, then 1/a equals…
- **options**:
  - A) √3 − 2
  - B) 2 + √3
  - C) 1/(2−√3) only, not simplified
  - D) 2 − √3
- **answer**: D
- **explanation**: Rationalise: 1/(2+√3) · (2−√3)/(2−√3) = 2−√3, since (2)²−(√3)²=1.
- **skill**: rationalise
- **difficulty**: hard

### Q21
- **stem**: A number of the form p/q with p, q integers and q ≠ 0 is called…
- **options**:
  - A) rational
  - B) irrational
  - C) integer
  - D) whole number
- **answer**: A
- **explanation**: Any number p/q with integers p, q and q ≠ 0 is a rational number. “Integer” is tempting because every integer can be written as n/1, but most such numbers, like 3/4, are not integers; “whole number” fails for the same reason and also for negatives. Irrational numbers are exactly the ones that cannot be written as p/q.
- **skill**: sets
- **difficulty**: easy
