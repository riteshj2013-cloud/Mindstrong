# Words

## Meta
- Grade: 2
- Subject: English
- Theme tags: words
- Source basis: NCERT Class 2 themes (original items only)
- Language: Grade 2 (very short sentences)

## Learning objectives
- Age-appropriate olympiad-lite practice for Grade 2.
- Set A and Set B have 16 MCQs each (32 total).

## Set A — 16 MCQs

### Q1
- stem: Word closest in meaning to "happy"?
- A: glad
- B: sad
- C: angry
- D: tired
- answer: A
- explanation: Glad means nearly the same as happy.

### Q2
- stem: Opposite of "hot"?
- A: warm
- B: cold
- C: boiling
- D: spicy
- answer: B
- explanation: Cold is the opposite of hot.

### Q3
- stem: A baby dog is called a…
- A: kitten
- B: cub
- C: puppy
- D: calf
- answer: C
- explanation: A baby dog is a puppy.

### Q4
- stem: Complete: as busy as a…
- A: stone
- B: pillow
- C: cloud
- D: bee
- answer: D
- explanation: As busy as a bee.

### Q5
- stem: Which word means "very big"?
- A: huge
- B: tiny
- C: thin
- D: soft
- answer: A
- explanation: Huge means very big.

### Q6
- stem: Rhymes with light?
- A: long
- B: night
- C: lamp
- D: leaf
- answer: B
- explanation: Night rhymes with light.

### Q7
- stem: Compound word: sun + flower =
- A: sunshine
- B: sunset
- C: sunflower
- D: sunlight
- answer: C
- explanation: sun + flower = sunflower.

### Q8
- stem: Prefix un- in "unhappy" means…
- A: very
- B: again
- C: before
- D: not
- answer: D
- explanation: un- means not.

### Q9
- stem: Synonym of begin?
- A: start
- B: end
- C: stop
- D: finish
- answer: A
- explanation: Start means nearly the same as begin.

### Q10
- stem: Antonym of full?
- A: packed
- B: empty
- C: filled
- D: loaded
- answer: B
- explanation: Empty is the opposite of full.

### Q11
- stem: A place where books are kept?
- A: kitchen only
- B: garage only
- C: library
- D: garden only
- answer: C
- explanation: A library keeps books.

### Q12
- stem: Which word is a naming word for a person?
- A: run
- B: blue
- C: quickly
- D: doctor
- answer: D
- explanation: Doctor names a person.

### Q13
- stem: Choose the polite word.
- A: please
- B: shut up
- C: move it
- D: hey you
- answer: A
- explanation: Please is polite.

### Q14
- stem: Plural of child?
- A: childs
- B: children
- C: childes
- D: child
- answer: B
- explanation: Children is the plural of child.

### Q15
- stem: Word for a person who teaches?
- A: driver only
- B: singer only
- C: teacher
- D: painter only
- answer: C
- explanation: A teacher teaches.

### Q16
- stem: Homophones: pair / …
- A: peer
- B: poor
- C: pour
- D: pear
- answer: D
- explanation: Pair and pear sound alike.
