## Interactive Lesson Outline

### step_1: Euclid's lemma
- **tts**: Every pair of positives has a unique quotient and remainder with 0 ≤ r < b.
- **check**: Remainder when 17 is divided by 5? — Answer: 2

### step_2: HCF via Euclid
- **tts**: Replace the larger by the remainder until you hit zero.
- **check**: HCF(48, 18)? — Answer: 6

### step_3: Fundamental theorem
- **tts**: Composites factor into primes in essentially one way.
- **check**: Prime factors of 60? — Answer: 2²×3×5

### step_4: Terminating decimals
- **tts**: After simplifying, only 2 and 5 in the denominator means terminating.
- **check**: Does 7/8 terminate? — Answer: Yes

## Set A

### Q01
- **stem**: Euclid's division lemma says that for positive integers a and b, there exist unique integers q and r such that a = bq + r, where —
- **options**:
  - A) r ≥ b
  - B) r can be any integer
  - C) 0 ≤ r < b
  - D) 0 < r ≤ b
- **answer**: C
- **explanation**: The remainder r satisfies 0 ≤ r < b.
- **difficulty**: mixed

### Q02
- **stem**: Using Euclid's algorithm, HCF(135, 225) equals —
- **options**:
  - A) 9
  - B) 45
  - C) 25
  - D) 15
- **answer**: B
- **explanation**: 225 = 135×1 + 90; 135 = 90×1 + 45; 90 = 45×2 + 0, so HCF = 45.
- **difficulty**: mixed

### Q03
- **stem**: If HCF(a, b) = 12 and a × b = 1800, then LCM(a, b) equals —
- **options**:
  - A) 150
  - B) 240
  - C) 180
  - D) 120
- **answer**: A
- **explanation**: HCF × LCM = product of numbers, so LCM = 1800/12 = 150.
- **difficulty**: mixed
