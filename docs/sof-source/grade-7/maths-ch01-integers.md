## Interactive Lesson Outline

### step_1
- Integers are … −2, −1, 0, 1, 2 …

### step_2
- Adding a negative is like subtracting.

### step_3
- Subtracting a negative becomes addition.

### step_4
- Same signs multiply/divide positive; opposite signs negative.

## Practice Set A

### Q01
- **stem**: Which of these is an integer?
- **options**:
  - A) −7
  - B) 3/4
  - C) √2
  - D) 0.333… repeating only as non-integer form
- **answer**: A
- **explanation**: Integers are …, −2, −1, 0, 1, 2, …. Fractions that are not whole numbers are not integers.
- **difficulty**: mixed

### Q02
- **stem**: What is the additive inverse of −15?
- **options**:
  - A) −15
  - B) 15
  - C) 1/15
  - D) 0
- **answer**: B
- **explanation**: A number plus its additive inverse equals 0, so −15 + 15 = 0.
- **difficulty**: mixed

### Q03
- **stem**: On a number line, which is farther left?
- **options**:
  - A) −3
  - B) 0
  - C) −12
  - D) 5
- **answer**: C
- **explanation**: More negative numbers lie farther to the left. −12 < −3.
- **difficulty**: mixed

### Q04

- **options**:

  - B) 13
  - C) 3
  - D) −13
- **answer**: D
- **explanation**: Adding two negatives: add absolute values and keep the negative sign → −13.
- **difficulty**: mixed

## Practice Set B

### Q01
- **stem**: Integers are closed under which operation among these?
- **options**:
  - A) Addition
  - B) Division
  - C) Taking square roots
  - D) Forming halves
- **answer**: A
- **explanation**: Sum of two integers is always an integer. Division may give a non-integer.
- **difficulty**: mixed

### Q02
- **stem**: Property shown by a + b = b + a for integers?
- **options**:
  - A) Associative
  - B) Commutative
  - C) Distributive
  - D) Identity
- **answer**: B
- **explanation**: Order of addition does not matter — commutative property.
- **difficulty**: mixed

### Q03
- **stem**: What is the additive identity for integers?
- **options**:
  - A) 1
  - B) −1
  - C) 0
  - D) None
- **answer**: C
- **explanation**: a + 0 = a for every integer a.
- **difficulty**: mixed
