## Practice Set B

### Q01
- **stem**: Solve: 7x − 3 = 4x + 12.
- **options**:
  - A) 5
  - B) 3
  - C) 9
  - D) 15
- **answer**: A
- **explanation**: 7x − 4x = 12 + 3 → 3x = 15 → x = 5.
- **difficulty**: mixed

### Q02
- **stem**: Solve: 3(x − 4) = 2(x + 1).
- **options**:
  - A) 10
  - B) 14
  - C) −14
  - D) 2
- **answer**: B
- **explanation**: 3x − 12 = 2x + 2 → x = 14.
- **difficulty**: mixed

### Q03
- **stem**: The sum of three consecutive integers starting at n is 54. Find n.
- **options**:
  - A) 18
  - B) 16
  - C) 17
  - D) 15
- **answer**: C
- **explanation**: n + (n+1) + (n+2) = 54 → 3n + 3 = 54 → n = 17.
- **difficulty**: mixed
